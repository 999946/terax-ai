# Terax 功能清单

> 适用版本：0.8.15 · 文档性质：软件功能总览。本文只罗列功能，不涉及实现方案。架构权威来源见 `TERAX.md`。

**Terax** 是一款开源、轻量、以终端为优先的 AI 原生开发环境（ADE）。终端优先，自带 AI 侧栏、代码编辑器、文件浏览器、源码控制、Web 预览等工具，极简且无遥测。

---

- 工作空间（Spaces）
  1. 新建工作空间
     - 从任意目录创建
  2. 切换工作空间
  3. 重命名工作空间
  4. 删除工作空间
  5. 为工作空间设置颜色标识
  6. 为每个工作空间独立持久化标签页布局
  7. 目录变更时自动同步
  8. 本地 / 远程工作区环境选择（含 WSL）

- 终端（Terminal）
  1. 原生交互式终端
     - 高性能 WebGL 渲染
     - 配色由主题引擎驱动
  2. 多个终端标签页与分栏
     - 最多 4 分栏
  3. 调整字号、字体、光标样式
  4. 文件拖入终端自动补全路径
  5. 终端内可点击链接
  6. 后台 agent 活动提示
  7. 终端会话持久化
     - 切换标签页不中断后台运行
  8. Shell 集成增强
     - 多种 Shell（zsh / bash / fish / pwsh 等）
     - 命令提示符边界识别
     - 自动感知当前目录

- 代码编辑器（Editor）
  1. 多标签页与分栏
  2. 多语言语法高亮与解析
     - 内置 50+ 语言定义
  3. Vim 模式
  4. 代码诊断提示
  5. 编辑器主题跟随整体主题或独立设置
  6. 查找替换与跳转
     - 正则搜索
     - 跳转到指定行
  7. 保存时自动格式化
     - 支持 biome / prettier / ruff / rustfmt / gofmt 等
  8. 保存时冲突检测，避免静默覆盖
  9. 大文件支持与大小上限提示
  10. AI 代码补全（行内补全）
  11. AI 改动逐 hunk 预览、接受或拒绝
  12. Git 差异分栏
  13. Markdown 与 .env 等多类特殊文件编辑
  14. 新建文件对话框

- 文件浏览器（Explorer）
  1. 文件树浏览
  2. 文件搜索
  3. 内容搜索
  4. 新建 / 重命名 / 删除 / 复制文件与目录
  5. 自然（数字感知）排序
  6. 丰富文件图标集
  7. 键盘导航
  8. 目录变更实时监听刷新

- 语言服务器（LSP）
  1. 按需启用语言服务器，未启用零开销
  2. 多语言支持
     - TypeScript / rust-analyzer / pyright / ruff / gopls 等
     - 支持自定义 stdio 服务器
  3. 状态栏提示一键启用或安装
  4. 代码诊断展示
  5. 引用跳转
  6. 智能会话管理
     - 按工作区复用
     - 空闲自动回收

- 源码控制（Source Control）
  1. 查看文件变更
     - 区分已暂存 / 未暂存
  2. 暂存 / 取消暂存
  3. 丢弃改动
  4. 提交
  5. 拉取 / 推送
  6. 多 Git 仓库作为管理目标
  7. 分支管理
     - 查看分支
     - 切换分支

- Git 图谱（Git History）
  1. 提交历史图谱
     - 可视化分支拓扑与泳道配色
  2. 提交详情查看
  3. 提交搜索
  4. 一键跳转远程仓库网页

- 网页预览（Preview）
  1. 内嵌网页预览
  2. 地址栏导航
  3. 资源预览
  4. 自动检测本地开发服务器并提示打开

- Markdown
  1. Markdown 渲染预览
  2. 编辑 / 预览模式切换
  3. 文档内链接跳转
  4. 可点击任务复选框与代码块高亮

- AI 助手（AI）
  1. 模型接入
     - 支持 OpenAI / Anthropic / Google / xAI / Cerebras / Groq / DeepSeek / Mistral / OpenRouter 等提供商
     - 支持本地模型（Ollama / LM Studio / MLX）
     - 支持自定义 Base URL（OpenAI 兼容接口）
     - 自带 Key（BYOK）或本地离线
  2. 密钥安全存储
     - 密钥存于系统钥匙串，绝不下发到设置或本地存储
  3. 对话交互
     - 分栏式聊天对话
     - 会话持久化与自动命名
     - 附带附件与终端 / 编辑器选中内容作为上下文
     - 语音输入
     - 可复用提示片段（`#handle`）
  4. 代码能力
     - 读取文件
     - 列出目录
     - 搜索与内容检索
     - 编辑文件
     - 创建目录与文件
     - 重命名 / 删除文件
     - 在终端执行一次性命令
     - 挂载长驻代理 shell 会话
     - 管理后台进程（如 dev server）
     - 危险操作需用户确认
     - 敏感路径访问拦截（如 .env、.ssh）
  5. 编辑预览
     - AI 改动逐 hunk 接受 / 拒绝后再写盘

- Agent
  1. 内置 Terax Agent
  2. 接入终端编码 Agent
     - Claude Code / Codex / Gemini CLI / OpenCode / Grok 等
  3. 子 Agent 调度
  4. Agent 启动
     - 一次构建 1-4 分栏面板
     - 各 Agent 启动命令持久化
  5. Agent 通知管理
     - 通知铃铛
     - 后台活动提示
     - 为终端 Agent 安装通知挂钩

- 命令面板（Command Palette）
  1. 命令搜索与执行
  2. 模糊搜索
  3. 模式切换
  4. 最近使用记录
  5. 内容搜索

- 主题（Theme）
  1. 内置多套预设主题
     - terax-default / xcode / claude / kanagawa / kanagawa-dragon / tokyo-night / catppuccin / rose-pine / everforest / nord / gruvbox / dracula / solarized / tide / sage / caffeine 等
  2. 自定义主题
  3. 编辑器主题独立配对
  4. 可选背景图
  5. 窗口毛玻璃效果

- 标签页与分栏（Tabs）
  1. 多开 / 关闭 / 重排
  2. 多种标签类型
     - 终端 / 编辑器 / 预览 / Markdown / AI 差异 / Git 差异 / Git 图谱等
  3. 快捷切换（Alt 切换器）
  4. 新标签菜单
  5. 后台 agent 活动订阅

- 侧栏（Sidebar）
  1. 各视图切换
  2. 宽度拖拽与持久化

- 状态栏（Status Bar）
  1. 当前目录面包屑
  2. 诊断徽标
  3. 工作区环境选择器
  4. AI 工具状态指示

- 设置（Settings）
  1. 主题设置
  2. 编辑器 / 终端字体与字号
  3. 自动换行
  4. 光标样式
  5. 独立设置窗口，按分区直达

- 快捷键（Shortcuts）
  1. 快捷键注册与触发
  2. 作用域管理
  3. 按键标签显示

- 国际化（i18n）
  1. 多语言支持
     - 中 / 英 / 西 / 德 / 法 / 日 / 韩 / 葡 / 波 / 俄 / 印尼 / 印地等

- 插件系统（Plugin）
  1. 插件注册 / 删除 / 启用
  2. 插件事件派发
  3. 插件快照与读写

- 更新（Updater）
  1. 自动检查更新
  2. 下载更新
  3. 安装更新

- 命令行控制（CLI Control）
  1. 通过 CLI 控制前端
  2. 本地控制服务对接

- 工作区授权与安全
  1. 文件 / 进程 / 命令访问均经授权边界
  2. 工作区授权注册表
     - spawn / git / AI 的目录须在授权范围内
  3. AI 网络代理防护
     - 仅允许 http(s)
     - 阻断云元数据 / 内网地址
     - 防 DNS 重绑定
     - 请求头净化
  4. 敏感路径访问拦截
  5. 危险操作确认
  6. 终端输出控制序列按白名单处理
